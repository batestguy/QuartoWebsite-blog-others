The standard error, derived in bands

book-revisions
Casella and Berger get Var(X-bar) = sigma squared over n from one expansion and one substitution. Here every equation carries its own numbered R line, in seven bands — ending with the check, the plug-in, Efron’s bootstrap, and why quartering the error needs quadrupling the sample.

Claim

Casella and Berger prove \(\operatorname{Var}(\bar X)=\sigma^2/n\) — Theorem 5.2.6(b), p. 214 — and stop there. The standard error is its square root.

The proof is one idea. Square the deviation, expand the square into \(n^2\) terms, take the expectation of each: the \(n\) diagonal terms each expect \(\sigma^2\), independence kills all \(n(n-1)\) cross terms, and \(n\sigma^2/n^2\) cancels once to \(\sigma^2/n\). Nothing is estimated and no distribution is assumed.

Code, maths, English

Code Maths English
BAND 1 — the three numbers
L1 ↔︎ (1.1) mu <- 5 (1.1) \(\mu := 5\) A definition, not a measurement: <- and \(:=\) say the same thing.
L2 ↔︎ (1.2) sigma <- 1.3 (1.2) \(\sigma := 1.3,\quad\sigma^2 = 1.69\) 1.3 cm of spread; 1.69 the same fact in cm². The square root between them is the whole post.
L3 ↔︎ (1.3) n <- 25 (1.3) \(n := 25\) How many measurements: chosen, not estimated.
BAND 2 — one sample, and its deviations
L4 ↔︎ (2.1) x <- rnorm(n, mu, sigma) (2.1) \(X_1,\dots,X_n \overset{\text{iid}}{\sim} N(\mu,\sigma^2)\) 25 draws. The normal supplies independent numbers; no later line uses its shape.
L5 ↔︎ (2.2) z <- x - mu (2.2) \(z_i := X_i - \mu,\qquad E[z_i] = 0\) Centre on the truth, not on mean(x); after this line \(\mu\) is gone.
BAND 3 — the square splits into two blocks
L6 ↔︎ (3.1) M <- outer(z, z) (3.1) \(\Big(\sum_i z_i\Big)^2 = \sum_i z_i^2 + \sum_{i\ne j} z_i z_j\) All 625 products of two deviations, in one 25×25 matrix.
L7 ↔︎ (3.2) sum(diag(M)) (3.2) \(\sum_i z_i^2 \quad\) — \(n\) diagonal terms prints 66.76 — this sample’s block. Band 4 prints another number, and both are right.
L8 ↔︎ (3.3) sum(M) - sum(diag(M)) (3.3) \(\sum_{i\ne j} z_i z_j \quad\) — \(n(n-1)\) cross terms prints 160.7; with L7 that is 227.4 \(=(\sum z_i)^2\), exactly.
L9 ↔︎ (3.4) n + n * (n - 1) (3.4) \(n + n(n-1) = n^2\) prints 625, the matrix’s own cell count: \(n\) squares, \(n(n-1)\) crosses, nothing else.
BAND 4 — take the expectation of each block
L10 ↔︎ (4.1) S <- matrix(rnorm(N * n, mu, sigma), N, n) - mu (4.1) \(N\) independent samples of size \(n\), each centred the same way 100,000 repeats of band 2: an expectation, computed.
L11 ↔︎ (4.2) mean(rowSums(S^2)) (4.2) \(E\Big[\sum_i z_i^2\Big] = n\sigma^2\) prints 42.28 ± 0.03782 against \(n\sigma^2 = 42.25\). L7’s 66.76 was not an error: the average is not the sample.
L12 ↔︎ (4.3) mean(rowSums(S)^2 - rowSums(S^2)) (4.3) \(E[z_iz_j] = \operatorname{Cov}(X_i,X_j) = 0,\quad i \ne j\) prints 0.04796 ± 0.1851 against an exact 0. Independence enters here and nowhere else.
L13 ↔︎ (4.4) n * sigma^2 (4.4) \(n\sigma^2 = 42.25\) 42.25 exactly — the algebra, before any data.
BAND 5 — add the blocks, divide by \(n^2\), then root
L14 ↔︎ (5.1) (1 / n^2) * (n * sigma^2) (5.1) \(\operatorname{Var}(\bar X) = \dfrac{1}{n^2}\,n\sigma^2 = \dfrac{\sigma^2}{n}\) prints 0.0676 cm². One \(n\) cancels out of \(n\sigma^2/n^2\): that is Theorem 5.2.6(b).
L15 ↔︎ (5.2) sigma / sqrt(n) (5.2) \(\operatorname{SE}(\bar X) = \dfrac{\sigma}{\sqrt n}\) prints 0.26 cm — (5.1) rooted, not interchangeable with it.
BAND 6 — check the finished result by simulation
L16 ↔︎ (6.1) means <- replicate(N, mean(rnorm(n, mu, sigma))) (6.1) \(\bar X_1,\dots,\bar X_N\) from \(N\) independent samples 100,000 averages of 25 fresh measurements: the experiment the theorem predicts.
L17 ↔︎ (6.2) var(means) (6.2) \(\operatorname{Var}(\bar X) \approx \widehat{\operatorname{var}}\big(\{\bar X_k\}\big)\) prints 0.06734 against an exact 0.0676, ratio 0.9962: the averages land on (5.1).
L18 ↔︎ (6.3) sd(means) (6.3) \(\operatorname{SE}(\bar X) \approx \widehat{\operatorname{sd}}\big(\{\bar X_k\}\big)\) prints 0.2595 against 0.26 — (6.2) rooted and (5.2) agree to three digits.
BAND 7 — what the number is for
L19 ↔︎ (7.1) sizes <- c(n, 4 * n, 16 * n) (7.1) \(\operatorname{SE}(\bar X_n) = \dfrac{\sigma}{\sqrt n}\), so \(\operatorname{SE}_{4n} = \tfrac12 \operatorname{SE}_n\) and \(\operatorname{SE}_{16n} = \tfrac14 \operatorname{SE}_n\) No new derivation: the \(\sqrt n\) of (5.2) read at \(n\), \(4n\), \(16n\).
L20 ↔︎ (7.2) sd_sizes <- sapply(sizes, ...) (7.2) \(\widehat{\operatorname{SE}}\) at each of the three sizes prints 0.2589, 0.1297, 0.06467 against 0.26, 0.13, 0.065: quadrupling the sample halves the error (1.997 against 2, 4.003 against 4). Sixteen times the data buys a quarter, so halving again costs four times as much data.
L21 ↔︎ (7.3) se_hat <- sd(x) / sqrt(n) (7.3) \(\widehat{\operatorname{SE}} = \dfrac{s}{\sqrt n}\), where \(s^2 = \frac{1}{n-1}\sum_i (X_i - \bar X)^2\) prints 0.31 against a true 0.26. Not a bug: that sample’s \(s\) is 1.55 cm against \(\sigma = 1.3\), so its honest bar is wider.
L22 ↔︎ (7.4) boot <- replicate(N, mean(sample(x, replace = TRUE))) (7.4) \(X^*_1, \dots, X^*_n\) drawn with replacement from \(x\) Efron’s route: resample the 25 numbers already held, 100,000 times. No formula, no \(\sigma\), no imagined data.
L23 ↔︎ (7.5) sd(boot) (7.5) \(\sqrt{\dfrac{n-1}{n}} \cdot \dfrac{s}{\sqrt n}\) prints 0.3035 against 0.3038 — ratio 0.979, which is \(\sqrt{(n-1)/n} = 0.9798\): the bootstrap reproduces the plug-in, low by exactly that finite-sample factor.
L24 ↔︎ (7.6) mean(abs(means - mu) <= 1.96 * se_exact) (7.6) \(\Pr\big(\lvert \bar X - \mu \rvert \le 1.96\,\sigma/\sqrt n\big) \approx 0.95\) prints 95.11 per cent. Not the derivation: a distance becomes a probability only with the shape of the scatter (§5.3, §5.5), and the check borrows means from band 6.
NoteWhere this comes from

The derivation. Casella & Berger, Statistical Inference, 2nd ed., §5.2. Lemma 5.2.5 (p. 213) states \(\operatorname{Var}\big(\sum g(X_i)\big)=n\operatorname{Var}g(X_1)\); its proof writes the variance as the expectation of a squared sum and counts \(n\) diagonal and \(n(n-1)\) cross terms. Theorem 4.5.5 makes each cross term a covariance; independence makes it zero. Theorem 5.2.6(b) (p. 214) takes \(g(x)=x/n\), giving \(\operatorname{Var}(\bar X)=n\cdot\sigma^2/n^2=\sigma^2/n\). Bands 2 to 5 are that proof with the expectations written out instead of cited, so that L12 is visibly the step where independence enters and nowhere else.

The name. §5.2 stops at the variance. The words “standard error” do not occur until §10.1.4, “Bootstrap Standard Errors”, p. 478. Taking the square root — (5.2) — is the step every applied text adds and this one does not.

The bootstrap. Efron, B. (1979), “Bootstrap methods: another look at the jackknife”, Annals of Statistics 7(1), 1–26. For the mean, the variance of the resampling distribution is exactly \(\frac{n-1}{n}\cdot\frac{s^2}{n}\), not approximately so, which is where the \(\sqrt{(n-1)/n}\) in (7.5) comes from and why band 7 can predict the bootstrap’s shortfall before running it.

The code. One chunk, include: false, labelled se-bands. Every number in the table is pulled from it as an inline r expression formatted to four significant figures; none is typed. set.seed(7) fixes the single sample in bands 2, 3 and 7, and set.seed(11) the 100,000 replicates in bands 4, 6 and 7, so the printed values are stable across renders. The scaling check in (7.2) uses N_scale <- 2e4 rather than N, because each of its repeats draws up to sixteen times as many numbers for a claim that is only a ratio; 20,000 repeats pin the ratio to three digits at a tenth of the cost.

About the sample in band 3. It is not typical, and it is not tuned. 66.76 against an expectation of 42.28 is roughly two standard deviations high. That gap is left in deliberately: it is the cleanest instance available of the difference between a realisation and its expectation, and a reader who has just seen both numbers in adjacent bands will not confuse them in band 5. The same wide sample is why the plug-in at (7.3) reads 0.31 where the truth is 0.26.

```{r}
#| label: se-bands
#| include: false

# ---- Every number in the table comes from here ------------------------------
#
# Two seeds, deliberately: one fixing the single sample in bands 2 and 3, one
# fixing the 100,000 replicates in bands 4 and 6. Both are set in advance, so
# the printed values are stable across renders without anything being typed.
#
# Band 1 is arithmetic on the truth about one measurement, in centimetres.
# Bands 2 to 5 are the proof. Band 6 checks it, and band 7 is what a reader
# does with the number afterwards: scaling, the plug-in, the bootstrap, and
# coverage. Nothing in bands 2 to 5 depends on either.

fmt <- function(x) format(x, digits = 4, scientific = FALSE)

mu    <- 5     # L1
sigma <- 1.3   # L2
n     <- 25    # L3

# Bands 2 and 3: one sample, and the square of its deviations split into
# diagonal and cross blocks.
set.seed(7)
x <- rnorm(n, mu, sigma)   # L4
z <- x - mu                # L5

M           <- outer(z, z)          # L6, all n^2 products
diag_block  <- sum(diag(M))         # L7, the n squares
cross_block <- sum(M) - diag_block  # L8, the n(n-1) crosses
term_count  <- n + n * (n - 1)      # L9

# Band 4: the same experiment 100,000 times, to take the expectation of each
# block. Centring the whole matrix at once is (4.1) applied to every row.
set.seed(11)
N <- 1e5
S <- matrix(rnorm(N * n, mu, sigma), N, n) - mu    # L10

diag_draws  <- rowSums(S^2)               # per-sample diagonal block
cross_draws <- rowSums(S)^2 - diag_draws  # per-sample cross block

m_diag    <- mean(diag_draws)             # L11
se_diag   <- sd(diag_draws) / sqrt(N)
m_cross   <- mean(cross_draws)            # L12
se_cross  <- sd(cross_draws) / sqrt(N)

# Bands 5 and 6.
var_mean <- (1 / n^2) * (n * sigma^2)     # L14, exact
se_exact <- sigma / sqrt(n)               # L15, exact

set.seed(11)
means <- replicate(N, mean(rnorm(n, mu, sigma)))   # L16
var_means <- var(means)                            # L17
sd_means  <- sd(means)                             # L18

# Band 7: what the number is for. None of this feeds back into the proof.
sizes <- c(n, 4 * n, 16 * n)              # L19
N_scale <- 2e4   # fewer repeats here: each one now costs up to 16x the draws

set.seed(11)
sd_sizes <- sapply(sizes, function(k) sd(replicate(N_scale, mean(rnorm(k, mu, sigma)))))   # L20

se_hat <- sd(x) / sqrt(n)                 # L21, sigma replaced by the sample's s

set.seed(11)
boot <- replicate(N, mean(sample(x, replace = TRUE)))   # L22, resample the held sample
sd_boot <- sd(boot)                                     # L23

cover <- mean(abs(means - mu) <= 1.96 * se_exact)       # L24, uses band 6's means
```
